# voiceCheck

`voiceCheck` — это продвинутая система аналитики звонков, основанная на технологиях распознавания речи и больших языковых моделей (LLM). Решение анализирует телефонные разговоры из колл-центров и служб поддержки клиентов, обрабатывая как аудио, так и текстовое содержимое каждого вызова, и предоставляет такие инсайты, как анализ тональности, определение темы, выявление конфликтов, обнаружение нецензурной лексики и автоматическое резюме.

Когда аудиофайл попадает в директорию `.data/input`, конвейер обработки запускается автоматически, а итоговые данные сохраняются в базу данных.

- GPU с минимум 24 ГБ видеопамяти
- Учётная запись Hugging Face и токен доступа

- Один из следующих наборов учётных данных:
    - OpenAI API Key
    - Azure OpenAI (API Key, API Base URL, версия API)

## Архитектура

Конвейер обработки выполняется по шагам:

1. **Обнаружение диалога** — проверка, содержит ли аудиофайл речь.
2. **Улучшение речи** — шумоподавление и повышение качества.
3. **Отделение вокала** — выделение голоса с помощью Demucs.
4. **Диаризация** — разделение дикторов с помощью NVIDIA NeMo.
5. **Транскрипция** — преобразование речи в текст через `faster-whisper`.
6. **Принудительное выравнивание** — точная привязка слов к временным меткам.
7. **Восстановление пунктуации** — добавление знаков препинания.
8. **Сопоставление слов и дикторов** — кто что сказал.
9. **LLM-анализ** — определение ролей, темы, тональности, конфликтов и резюме.
10. **Сохранение в БД** — запись результатов в SQLite.

## Описание функций и модулей

В этом разделе перечислены все классы и функции, которые необходимы для работы системы.

### 1. Аудиомодули — `src/audio/`

#### `error.py`

- **`DialogueDetecting`** — определяет, содержит ли аудиофайл диалог. Если речь отсутствует или файл повреждён, обработка прекращается.
  - `process(audio_path)` — основной метод проверки.

#### `preprocessing.py`

- **`Denoiser`** — базовый класс для шумоподавления.
- **`SpeechEnhancement`** — продвинутое улучшение качества речи. Использует MPSENet и librosa.
  - `enhance_audio(input_path)` — возвращает путь к очищенному файлу.

#### `effect.py`

- **`DemucsVocalSeparator`** — отделяет голосовую дорожку от фоновой музыки и шума с помощью модели Demucs.
  - `separate_vocals(audio_path)` — выделяет вокал.

#### `processing.py`

- **`AudioProcessor`** — конвертация формата, нормализация громкости, подготовка моно-дорожки.
- **`Transcriber`** — обёртка над `faster-whisper` для распознавания речи.
  - `transcribe(audio_path)` — возвращает сегменты с временными метками.
- **`PunctuationRestorer`** — восстанавливает знаки препинания в тексте на основе модели `deepmultilingualpunctuation`.

#### `alignment.py`

- **`ForcedAligner`** — принудительно выравнивает слова с временными метками с помощью CTC. Точность до миллисекунды.

#### `io.py`

- **`SpeakerTimestampReader`** — читает RTTM-файл, полученный от NeMo, и извлекает временные интервалы каждого диктора.
- **`TranscriptWriter`** — записывает результирующий транскрипт в форматах `.txt` и `.srt`.

#### `analysis.py`

- **`WordSpeakerMapper`** — сопоставляет каждое слово с конкретным диктором по временным меткам.
- **`SentenceSpeakerMapper`** — группирует слова в предложения и приписывает их дикторам.
- **`Audio`** — извлекает свойства аудио: длительность, частота дискретизации, громкость, RMS, число каналов и т. п.

#### `metrics.py`

- **`SilenceStats`** — рассчитывает статистику пауз в речи.
  - Стандартное отклонение и среднее (`std`-метод).
  - Медиана и межквартильный размах (`median + IQR`).
  - Суммарное «значимое» молчание выше порога.

#### `utils.py`

- **`Formatter`** — форматирование вывода (текст, временные коды, JSON).
- **`TokenizerUtils`** — вспомогательные функции токенизации.

### 2. Текстовые модули — `src/text/`

#### `model.py`

- **`LanguageModel`** — абстрактный базовый класс LLM.
- **`LLaMAModel`** — реализация Llama (через Hugging Face).
- **`OpenAIModel`** — клиент OpenAI API.
- **`AzureOpenAIModel`** — клиент Azure OpenAI.
- **`ModelRegistry`** — реестр доступных моделей.
- **`ModelFactory`** — фабрика для создания нужного экземпляра модели.
- **`LanguageModelManager`** — высокоуровневый менеджер, управляющий жизненным циклом модели.

#### `llm.py`

- **`LLMOrchestrator`** — оркестратор запросов к LLM. Выполняет последовательно:
  - Классификацию ролей дикторов (агент / клиент).
  - Анализ тональности по каждому высказыванию.
  - Поиск нецензурной лексики.
  - Определение темы разговора.
  - Выявление конфликтных моментов.
  - Формирование краткого резюме разговора.
- **`LLMResultHandler`** — валидирует, парсит и нормализует ответы LLM в структуру, пригодную для записи в БД.

#### `prompt.py`

- **`PromptManager`** — загружает шаблоны из `config/prompt.yaml`, подставляет параметры и формирует финальный промпт.

#### `utils.py`

- **`Annotator`** — добавляет к высказываниям мета-информацию (тональность, флаги, теги).

### 3. База данных — `src/db/`

#### `manager.py`

- **`Database`** — обёртка вокруг SQLite.
  - `connect()` — открыть соединение.
  - `execute(sql, params)` — выполнить запрос.
  - `insert_audio_properties(...)` — записать свойства аудиофайла.
  - `insert_utterance(...)` — записать отдельное высказывание.
  - `fetch_topics()` / `insert_topic(...)` — работа со словарём тем.
  - `close()` — закрыть соединение.

SQL-схема и запросы лежат в `src/db/sql/`.

### 4. Утилиты — `src/utils/`

#### `utils.py`

- **`Logger`** — единая обёртка над `logging` с форматом и ротацией.
- **`Cleaner`** — удаляет временные файлы (`.temp/`) после завершения обработки.
- **`Watcher`** — наследник `FileSystemEventHandler` (`watchdog`), отслеживает появление новых файлов в `.data/input` и автоматически запускает конвейер.

## База данных

Используется встроенная SQLite. Основные таблицы:

- `Audio` — свойства аудиофайлов (длительность, частота, громкость, путь и т. п.).
- `Topic` — справочник тем разговоров.
- `Utterance` — отдельные высказывания с привязкой к диктору, времени, тональности и флагам.

Схема инициализируется командой:

```bash
sqlite3 .db/voiceCheck.sqlite < src/db/sql/Schema.sql
```

## Запуск

### Однократный запуск на конкретном файле

```bash
python main.py
```

### Автоматический режим (наблюдение за директорией)

При запуске включается `Watcher`, который следит за `.data/input`. Любой новый аудиофайл сразу проходит весь конвейер.

### Запуск через systemd

```bash
sudo cp automation/service/voicecheck.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now voicecheck
```
